# Clink AI v2.1.1

发布日期：2026-07-31

## 账号与权限

- 移除 `admin`、`editor` 配合任意六位密码的演示登录兜底。
- 登录仅接受管理员在后台创建，或注册后经管理员批准且处于启用状态的成员账号。
- 后台入口仅对管理员显示；非管理员直接访问后台时进入无权限页面。
- 清理登录页中的演示账号提示、默认密码与默认成员种子数据。

## API 与模型

- API 配置升级为可累积的连接库，新增连接不再覆盖已有连接。
- 保留个人与平台添加的连接数据，并将运行数据存放于站点目录之外，发版覆盖静态文件时不会丢失。
- 工作台与智能体共用已配置且可用的模型列表。
- 每个智能体独立保存自己的模型选择，不再被工作台默认模型批量覆盖。
- 对旧版单连接配置提供自动迁移兼容。

## 工作台体验

- 修复智能体环形卡片旋转过程中周期性缩小、放大的跳动。
- 优化卡片选中、悬停与自动旋转之间的过渡连续性。
- 补充桌面端响应式布局，覆盖 1366x768、1440x900 与 1920x1080 等常见显示尺寸。
- 增加轻量进入与交互微动效，并尊重系统减少动态效果设置。

## 工程与部署

- 将大型单文件构建逻辑拆分为样式、启动、智能体桌面、无限画板与文档窗口模块。
- 增加 `npm run check:changed` 定向回归检查和 `npm run health` 项目健康检查。
- 增加单文件内联脚本语法校验，防止构建成功但预览空白。
- 部署改为仓库目录、站点目录、运行数据目录分离。
- 宝塔部署通过 PM2 运行后端 API，并由 Nginx 代理 `/api/`。

## 验证

- 后台生产构建通过。
- 单文件构建与定向检查通过。
- 登录兜底与敏感信息源码扫描通过。
- 模型多连接新增、路由和服务重启持久化验证通过。
- 常见桌面分辨率无横向溢出，智能体卡片持续旋转验证通过。
