# 待发版改动

## 管理员认证

- 管理员登录改为由 Node API 校验，不再依赖浏览器本地种子账号。
- 账号、密码和签名密钥从服务器私有环境读取，不提交到 GitHub。
- 管理员令牌使用服务端 HMAC 签名并设置有效期，默认拒绝旧版可伪造的成员令牌。
- 修复 Windows 环境下定向检查无法启动 npm 子进程的问题。

## 成员与注册

- 后台创建的成员改为持久化到服务器，可使用所建账号直接登录。
- 前台注册申请改为提交到服务器；管理员同意后账号立即生效，拒绝后不能登录。
- 成员密码使用带随机盐的 scrypt 哈希保存，接口和列表不再返回明文密码。
- 管理员首次打开成员页时会一次性迁移旧浏览器中的人员和待审核申请，并清除本地明文副本。
- 停用或删除成员后，其现有登录令牌与后续登录都会失效。

已发布内容见 `docs/RELEASE_NOTES_2.1.1.md`。
