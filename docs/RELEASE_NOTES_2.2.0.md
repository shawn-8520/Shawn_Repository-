# Clink AI v2.2.0

发布日期：2026-09-16

## 账号与管理

- 管理员和成员登录改为服务端校验，取消访客进入，未注册用户引导申请账号。
- 增加成员、注册申请与权限管理，完善后台认证与无权限状态。
- 平台管理员配置的 API 可供已批准成员共享使用，密钥仍保留在服务器私有配置中。

## AI 速记与工作台

- AI 速记升级为“链记成文”体验，优化页面背景、字体、文件弹窗和分类交互。
- 修复卡片对话、工作台模型提示、页签切换后弹窗残留等问题。
- 优化顶部导航、环绕视图、Skills 卡片密度与圆角，并更新品牌文案。

## 无限画布

- 完善文生图与图生图异步队列，显示排位、预计等待、重试次数和倒计时。
- 接入 AI Horde SDXL 免费免注册文生图/图生图，同时保留 Pollinations 带水印快速模型。
- 删除生成节点时同步取消队列任务；优化画布本地存储，避免配额超限导致页面卡顿。
- 画布项目内隐藏底部导航，返回工作台后自动恢复。

## 工程与发布

- 增加项目架构、开发规则、变更定向检查和健康检查。
- 重新构建单文件工作台、管理后台与无限画布发布产物。

## 验证

- 画布生图、排队、重试、页签切换和模型下拉已按实际使用路径验证。
- `npm run check`、`npm run health`、单文件发布构建与 Git 格式检查通过后发布。
